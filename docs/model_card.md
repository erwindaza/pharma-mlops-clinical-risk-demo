# Model Card

## Model Name

`clinical_risk_xgboost`

## Intended Use

Educational clinical trial operational risk scoring demo for MLOps interviews.

## Not Intended Use

This model is not intended for diagnosis, treatment decisions, patient triage, medical device use, or real clinical recommendations.

## Dataset

Synthetic data generated by `training/data_generator.py`. No real patient data, patient identifiers, or PHI are used.

## Features

Features include age, encoded sex, prior conditions count, lab score values, visit adherence, site delay, protocol complexity, dropout signal, medication count, adverse event history count, country risk index, site enrollment rate, and days since last visit.

## Metrics

Training logs ROC AUC, F1, precision, recall, and accuracy to MLflow.

## Limitations

Synthetic data does not represent real clinical trial populations. Feature relationships are intentionally simplified for a platform engineering demo.

## Ethical Considerations

Any real-world clinical model would require data governance, fairness analysis, validation, clinical review, privacy controls, and regulatory assessment.

## Monitoring Plan

Track request counts, prediction distributions, latency, error rates, input drift, model version, and service health.

## Retraining Plan

Retraining should be triggered by material data drift, degraded monitored metrics, protocol changes, or approved model improvement work.
