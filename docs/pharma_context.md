# Pharma Context

Clinical trials are expensive, operationally complex, and highly regulated. A risk scoring workflow can help operations teams prioritize monitoring, but regulated environments require stronger engineering discipline than a notebook-only prototype.

This project highlights:

- Synthetic data by default.
- Reproducible training with fixed seeds.
- Experiment tracking with MLflow.
- Versioned artifacts and metadata.
- API contracts with typed schemas.
- Containerized serving.
- CI validation before changes merge.
- Optional least-privilege AWS infrastructure.

The model is intentionally simple. The point is to demonstrate how ML can be operationalized responsibly in a pharma-style platform.
